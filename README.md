## 🚀 গিটহাব থেকে সরাসরি APK বানানোর নিয়ম (GitHub Actions)
এই রিপোজিটরিতে অটোমেটিক APK তৈরির ফাইল যুক্ত রয়েছে:
1. কোডগুলো আপনার GitHub রিপোজিটরিতে আপলোড করুন (`main` ব্রাঞ্চে)।
2. GitHub-এর **Actions** ট্যাবে যান।
3. **Build Android APK** ওয়ার্কফ্লোটি অটোমেটিকভাবে রান হবে।
4. কয়েক মিনিট পর **Artifacts** সেকশনে সরাসরি তৈরি করা `app-debug.apk` ফাইলটি ডাউনলোডের জন্য পেয়ে যাবেন!

## 🌐 গিটহাব পেজেস (GitHub Pages) দিয়ে অ্যাপ চালানোর নিয়ম
1. GitHub রিপোজিটরির **Settings**-এ যান।
2. বামদিকের মেনু থেকে **Pages** সিলেক্ট করুন।
3. **Branch** হিসেবে `main` এবং ফোল্ডার `/root` সিলেক্ট করে **Save** করুন।
4. একটি লাইভ লিঙ্ক পাবেন (যেমন: `https://yourusername.github.io/repo-name/`)।
5. মোবাইলে লিঙ্কটি খুলে Chrome-এর মেনু থেকে **"Install app"** চাপলে ফোনে অ্যাপ ইনস্টল হয়ে যাবে।
